# Приложения для Belgee X70

Сайт: **https://oleg-rit.github.io/belgee-x70-apps/**

Приложения для штатного ГУ Belgee X70 (прошивка `SW0NL3B0411H5177.00115`, Android 5.1):

- **Panel X70**: своя нижняя панель, окно климата, центр управления, подогревы с таймером, зимний режим, заставка.
- Архив: Экран X70, WheelHeat, Bluetooth X70, Перезагрузка ГУ, Рабочий стол X70.

Файлы для скачивания лежат на странице [Releases](https://github.com/Oleg-rit/belgee-x70-apps/releases/latest). Установка и удаление делаются с флешки, инструкция есть на сайте.

⚠️ Всё ставите на свой страх и риск, гарантий никаких. Это любительский проект владельцев, он не связан с Belgee, Geely или Neusoft.
